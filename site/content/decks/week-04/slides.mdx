  { l: 1, h: "Finds “unknown unknowns”" },

<Slide title={"EDA Caveats"}>

<Bullets items={[
  { l: 1, h: "Confirmation Bias – the tendency to subconsciously identify, prefer, or interpret information in a way that confirms pre-existing beliefs or hypotheses" },
  { l: 2, h: "Look for patterns that contradict initial ideas or expectations" },
  { l: 2, h: "Require higher burden of proof for conclusions that align with priors" },
  { l: 1, h: "Correlation vs. Causation – relationships discovered with EDA do not necessarily entail causal (functional) relationships" },
  { l: 2, h: "Observing that two variables move together during EDA does not prove that one causes the other" },
  { l: 2, h: "Establishing causal relationships requires experiments or causal inference" },
  { l: 2, h: "*Note: correlation is not causation, but they are highly correlated*" },
]} />

</Slide>

<Slide title={"Caution"}>

<Bullets items={[
  { l: 1, h: "“There are 3 kinds of lies: lies, damned lies, and statistics.” ~ Mark Twain" },
  { l: 1, h: "Visualizations can be misleading (intentionally or not)" },
  { l: 1, h: "Important to consider whether the interpretation of your visualization will be what is intended" },
]} />

</Slide>

<Bullets items={[
  { l: 1, h: "Truncation: Truncating axes can make variation appear greater or less" },

  { l: 2, h: "Log-scale axes are an example of well-understood non-constant scaling" },
  { l: 2, h: "Twin axes: A second axis can be misleading if using same units as first" },

<Slide title={"Cherry-Picking Data"}>

<Bullets items={[
  { l: 1, h: "Including only those observations that support a specific conclusion or omitting contradictory evidence" },
  { l: 1, h: "Removing outliers without justification can present a cleaner, but potentially misleading, picture" },
  { l: 1, h: "Selecting sub-group may imply the results generalize to the full group" },
]} />

</Slide>

<Slide title={"Misleading Aggregation"}>

<Bullets items={[
  { l: 1, h: "Using the mean for highly skewed data can be misleading, where the median might be better" },
  { l: 1, h: "Aggregating data can mask recent changes in trends" },
]} />

</Slide>
