<Slide title={"Descriptive Models"}>

<Bullets items={[
  { l: 1, h: "Intent is to describe, or capture something" },
  { l: 1, h: "Lots of learning about the data and setting" },
  { l: 2, h: "Your accounting domain knowledge is critical here!" },
  { l: 1, h: "Typically where we do exploratory data analysis" },
  { l: 1, h: "Often utilizing summary statistics, simple regressions" },
  { l: 2, h: "Example: Assets & Liabilities have R2 of 99%" },
  { l: 2, h: "*Note!* Running a regression at this stage doesn’t imply causality. It just shows us average relationships." },
]} />

</Slide>

<Slide title={"Diagnostic Models"}>

<Bullets items={[
  { l: 1, h: "Intent is to take the next step and learn *why* what you observed happened" },
  { l: 1, h: "The validity of the results relies *entirely* on the model" },
  { l: 1, h: "This is where most economists live" },
  { l: 2, h: "They are notoriously averse to predicting the future!" },
  { l: 1, h: "Often done with regressions/classifications" },
  { l: 2, h: "Outlier analysis for audit / forensic accounting" },
  { l: 2, h: "Causal models to identify true relationships" },
]} />

</Slide>

<Slide title={"Predictive Models"}>

<Bullets items={[
  { l: 1, h: "Intent is to use your knowledge to model new outcomes (i.e. predicting the future)" },
  { l: 1, h: "Also used to understand what *would have* happened if different decisions had been made" },
  { l: 1, h: "Very dependent on model and assumptions" },
  { l: 2, h: "Was data used “normal” or representative?" },
  { l: 2, h: "Will assumptions change going forward (e.g. interest)?" },
  { l: 1, h: "Often conflated with diagnostic models" },
]} />

</Slide>

<Slide title={"Prescriptive Models"}>

<Bullets items={[
  { l: 1, h: "Intent is to decide what actions to take" },
  { l: 2, h: "Flow-charts to guide decisions" },
  { l: 2, h: "Models with turnable dials to perform *what-if* analyses" },
  { l: 1, h: "Can result in a firm conclusion, or a data-backed input for decision-makers" },
  { l: 1, h: "Should factor in harder-to-model inputs, like risk" },
  { l: 1, h: "Careful about relying on predictive models of causality (the point of choosing is to change things!)" },
]} />

</Slide>

<Slide title={"Modeling Caveats"}>

<Bullets items={[
  { l: 1, h: "Most modeling boils down to using historical data to make inferences about the future" },
  { l: 2, h: "Correlational approaches (most machine learning) often cannot predict what it has not “seen”" },
  { l: 2, h: "Modeling the structure (most economics) often will not pick up real world complexity, and parameters are determined by correlational approaches" },
  { l: 1, h: "It all depends on the assumptions (data and model)" },
]} />

</Slide>

<Slide title={"From theory to practice"}>

<Bullets items={[
  { l: 1, h: "An analytical model is usually defined as a relationship with unknown quantities" },
  { l: 2, h: "E.g. Y = m*x + b" },
  { l: 1, h: "Fitting is estimating the unknown quantities" },
  { l: 2, h: "E.g. the *m* and *b*" },
  { l: 1, h: "*Example:* Altman’s Z Score – bankruptcy prediction" },
  { l: 1, h: "Z = 1.2 WCap + 1.4 RE + 3.3 EBIT + 1 Rev + 0.6 MVE" },

]} />

</Slide>

<Slide title={"Garbage in, Garbage out"}>

<Bullets items={[
  { l: 1, h: "Random errors (called noise) results in worse measures and outcomes, but randomly" },
  { l: 2, h: "E.g. predicting default risk inaccurately" },
  { l: 1, h: "Errors all in the same direction (called bias) can result in consistently wrong results" },
  { l: 2, h: "E.g. always underestimating default risk" },
  { l: 1, h: "Minimize noise, beware bias" },
]} />

</Slide>

<Slide title={"Correlation is not Causation"}>

<Bullets items={[
  { l: 1, h: "Important to differentiate when making decisions" },

</Slide>
