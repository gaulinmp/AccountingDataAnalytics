<Slide title={"Parametric vs Non-parametric"}>

<Bullets items={[
  { l: 1, h: "Parametric models specify the relationships between variables and the outcome" },

<Slide title={"Solution? Counterfactual!"}>

<Bullets items={[
  { l: 1, h: "Jargon:" },
  { l: 2, h: "Treatment: thing you’re studying the effect of (tax cut)" },
  { l: 2, h: "Treated firms: firms that get the treatment (got tax cut)" },
  { l: 2, h: "Control firms: firms that didn’t get treated (no tax cut)" },
  { l: 2, h: "“Treatment Effect” is estimated effect of treatment" },
  { l: 3, h: "= Outcometreated – Outcomecontrol" },
]} />

</Slide>

<Slide title={"Solution? Counterfactual!"}>

<Bullets items={[
  { l: 1, h: "Compare firm’s outcome when treatment occurs to that same firm’s outcome when treatment does not" },
  { l: 1, h: "Outcome when treatment does not occur is called the “counterfactual”" },
  { l: 2, h: "If firm is treated, how do we measure outcome when treatment does not occur (or vice versa)?" },
]} />

</Slide>

<Slide title={"Common Counterfactuals"}>

<Bullets items={[
  { l: 1, h: "Other firms that did not have treatment" },
  { l: 2, h: "Randomized control trials (gold standard): randomly assign treatment to firms, so only difference is treatment" },
  { l: 2, h: "Pseudo-experiments: find setting in which treatment occurring is *effectively* random (e.g. tax cut for firms > 1B)" },
  { l: 1, h: "Same firm before treatment occurred" },
  { l: 1, h: "Difference in difference: both of the above" },
  { l: 1, h: "*Note*: all these are estimated as averages across firms" },
]} />

</Slide>

<Slide title={"Difference in Difference"}>

<Bullets items={[
  { l: 1, h: "Looking at firm’s change due to treatment isn’t enough if untreated firms *also* changed" },
  { l: 1, h: "Example:" },
  { l: 2, h: "Firms that got PPP loans saw huge declines in sales" },
  { l: 2, h: "So PPP loans caused loss in sales?" },
  { l: 2, h: "Firms that did not get PPP loans saw larger losses" },
  { l: 2, h: "Compared to counterfactual, firms with PPP loans had *relatively* higher sales (but still lower then w/o Covid)" },
]} />

</Slide>

<Slide title={"Caveats and Concerns"}>

<Bullets items={[
  { l: 1, h: "It all comes down to how good your counterfactual is" },
  { l: 1, h: "Anything that is different between treatment and control could potentially cause the estimated effect" },
  { l: 2, h: "Called omitted variables or measurement error" },
  { l: 1, h: "Solutions to identify causality limit generalizability" },
  { l: 1, h: "If you can’t define how treatment results in outcome (the mechanism), be very skeptical" },
  { l: 2, h: "If you can, then that’s potentially testable" },
]} />

</Slide>
