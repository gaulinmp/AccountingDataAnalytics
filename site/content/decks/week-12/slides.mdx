<Slide title={"How LLMs process information"}>

<Bullets items={[
  { l: 1, h: "LLM applies its pre-trained knowledge (weights) to the specific text/files you provide it (context)" },
  { l: 2, h: "The interaction of these two is what provides functionality, but also uncertainty" },
  { l: 1, h: "In regression terms: next word = m * X" },
  { l: 2, h: "X is the context (input data)" },
  { l: 2, h: "m is the weights (learned coefficients)" },
  { l: 1, h: "*Prompt Engineering* is finding best context for a task" },
]} />

</Slide>

<Slide title={"Weights and Context"}>

<Bullets items={[

<Slide title={"In-weight knowledge"}>

<Bullets items={[
  { l: 1, h: "LLM training sets the >1Trillion coefficients (weights)" },
